One line of at most 200 characters: the phone battery's final message to the charger it waited for all day.

> we had a good run. you kept me warm all night, and i still left you for a stranger's usb port. don't wait up. i'm at 1% and he's at 100%.

The line is 137 characters, inside the 200-character limit. The joke is a breakup text, not a dying complaint: the battery doesn't just fade out, it confesses it cheated on the charger with a stranger's USB port — and the punchline lands on the last words, with the rival charger sitting pretty at 100%.

## How it works

`main.ts` writes the line above to `/output/entry.txt` (Node 22+).

```sh
node main.ts
```
